# Keyless for Web 原型说明

## 目标
- 构建具备点击/跳转交互的网页原型（非真实功能）。
- 原型包含：官网页面、模拟插件 side panel、Google/Apple 登录弹窗。

## 范围与限制
- 仅实现交互和页面跳转，不实现真实登录、钱包创建等功能。
- 插件以网页浮层模拟，**side panel 始终嵌入官网页面右侧**。
- 官网页面为静态数字货币行情表格。

## 全局交互规则（必须遵守）
1. **side panel 固定在官网右侧**，流程中不跳转到其他页面展示。
2. **官网只在最终连接/断开时切换状态**：
   - 连接中/登录中/创建中不联动官网 UI。
3. **Apple 登录流程与 Google 流程一致**（同样的步骤与页面结构）。
4. **PIN 码表单不需要严格规则**，位数与校验可随意实现。
5. **删除钱包无二次确认**，删除后官网变为未连接。
6. **断开连接仅影响官网状态**，插件内部状态保持不变。
7. **钱包类型不匹配提示的“确定”按钮**：返回插件首页，不关闭 side panel。
8. **连接流程进行中**：官网“连接钱包”按钮置灰不可点击。
9. **弹窗点击遮罩关闭**：直接恢复到起点（回到当前插件首页状态）。
10. **成功页允许关闭**：返回插件首页（不自动连接官网）。

## 页面/弹窗清单与层级
1. 官网页面（行情表格）
2. 连接钱包弹窗（居中）
3. 安装提示弹窗（居中）
4. side panel（右侧固定）
5. Google/Apple 登录弹窗（居中覆盖）
6. PIN 表单（side panel 内）
7. 创建钱包 loading（side panel 内）
8. 连接成功页（side panel 内）
9. 插件首页（side panel 内）

层级关系：登录弹窗 > 安装提示弹窗 > 连接钱包弹窗 > side panel > 官网

## 状态模型
**状态变量**
- `pluginInstalled`: 是否安装插件
- `walletExists`: 是否存在钱包
- `walletType`: `Google` | `Apple` | `None`
- `siteConnected`: 官网是否已连接

**初始状态**
```
pluginInstalled = false
walletExists = false
walletType = None
siteConnected = false
```

## 关键事件与状态转移（摘要）
- 点击“连接钱包” → 打开连接钱包弹窗
- 选择 Google/Apple：
  - `pluginInstalled=false` → 安装提示弹窗
    - “前往谷歌商店” → 打开商店链接（可用新标签页模拟），**5 秒后在官网页显示 side panel**
    - “我已安装完成” → `pluginInstalled=true`，立即显示 side panel
  - `pluginInstalled=true`：
    - `walletExists=false` → 进入登录 + PIN + 创建钱包流程
    - `walletExists=true && walletType=选择类型` → 直接展示钱包并确认连接
    - `walletExists=true && walletType!=选择类型` → 显示不匹配提示
- 点击官网“断开连接” → `siteConnected=false`（插件状态不变）
- 插件首页“删除钱包” → `walletExists=false`、`walletType=None`、`siteConnected=false`

## 交互流程（分场景）

### A. 未安装插件
1. 官网右上角点击“连接钱包” → 打开连接钱包弹窗（居中）。
2. 选择 Google/Apple 登录 → 出现安装提示弹窗：
   - 文案：`请安装 OneKey 插件继续`
   - 按钮：`前往谷歌商店`、`我已安装完成`
3. 点击“前往谷歌商店” → 模拟打开商店链接；**5 秒后在官网页右侧显示 side panel**。
4. side panel 显示登录中加载文案，并弹出对应的登录弹窗（居中）。
5. 登录确认后：关闭登录弹窗 → side panel 进入 PIN 表单。
6. 提交 PIN → side panel 显示创建钱包 loading（3 秒）。
7. 成功页显示“已连接官网”与“确认”按钮。
8. 点击“确认” → 进入插件首页，官网切换为已连接状态。

**中途关闭弹窗处理**：
- 连接弹窗 / 安装提示 / 登录弹窗点击遮罩关闭 → **恢复到起点**。

### B. 插件已安装，但未创建钱包
1. 用户在插件首页删除钱包后，处于无钱包状态。
2. 官网点击“连接钱包” → 选择 Google/Apple。
3. 直接进入登录弹窗 → PIN 表单 → 创建钱包 loading → 成功页 → 插件首页。
4. 官网切换为已连接状态。

### C. 插件已安装，钱包已创建，且类型匹配
1. 官网点击“连接钱包” → 选择与现有钱包相同的类型。
2. side panel 直接展示钱包地址与“确定连接”按钮。
3. 点击“确定连接” → 官网切换为已连接状态。
4. side panel 保持插件首页展示钱包信息。

### D. 插件已安装，钱包已创建，但类型不匹配
1. 官网点击“连接钱包” → 选择与现有钱包不同的类型。
2. side panel 显示提示：
   - 文案：`您已创建了一个 Apple 账户的钱包，请使用 Apple 账户连接。`
   - 按钮：`登出 Apple 钱包并使用 Google 创建`、`确定`
3. 点击“登出并创建” → 清空钱包 → 进入登录 + PIN + 创建钱包流程。
4. 点击“确定” → 返回插件首页（side panel 不关闭），官网保持未连接。

## 具体界面说明

### 官网（行情表格）
- 右上角：
  - 未连接：`连接钱包` 按钮
  - 已连接：显示钱包地址 + `断开连接` 按钮
- 表格字段（示例）：资产 / 价格 / 24h 涨跌 / 市值 / 成交量
- 行数：5–8 行即可（数据可虚构）

### 连接钱包弹窗（居中）
- 按钮：`使用 Google 登录`、`使用 Apple 登录`
- 连接流程进行中时：按钮置灰不可点击

### 安装提示弹窗（居中）
- 文案：`请安装 OneKey 插件继续`
- 按钮：`前往谷歌商店`、`我已安装完成`
- 商店链接由需求方提供

### 登录弹窗（居中）
- 简单表单：账号 + 密码 + 确认按钮
- 确认后进入 PIN 流程

### PIN 表单（side panel 内）
- 自由设计输入框与确认按钮（无需严格校验）

### 创建钱包 loading（side panel 内）
- 文案：`正在创建您的钱包数据`
- 时长：3 秒

### 连接成功页（side panel 内）
- 文案：`已连接到官网`
- 按钮：`确认`
- 允许关闭：关闭后返回插件首页（不自动连接官网）

### 插件首页（side panel 内）
- 钱包卡片：
  - 名称：`Google Wallet` / `Apple Wallet`
  - 地址：示例 `0x4a3b...9c2e`
- 按钮：`删除钱包`

## 统一文案与时序
- 登录中：`正在登录您的 Google 账户` / `正在登录您的 Apple 账户`
- 创建钱包 loading：3 秒
- 前往谷歌商店后：5 秒后在官网显示 side panel

## 插件 side panel 面板控制（模拟）
- 提供“隐藏/显示”按钮模拟面板收起与展开。
- 提供“卸载插件”按钮模拟插件卸载：
  - 卸载后恢复到初始状态，可重新走完整流程。

## 非目标
- 不实现真实插件能力
- 不实现真实 OAuth 登录或钱包创建逻辑
